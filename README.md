# arhaanjain.github.io

Personal Jekyll homepage for Arhaan Jain.

## Customize

- Update the bio, research areas, projects, and education entries in `index.html`.
- Add your email in `_config.yml` so the contact links work.
- Replace the LinkedIn URL in `index.html` with your profile.
- Add a résumé at `assets/arhaan-jain-resume.pdf` if you want to link one from the hero.

GitHub Pages can build this site directly from the repository using the configured `jekyll-theme-minimal` theme. For a local preview, install Jekyll first and run `jekyll serve`, then open `http://localhost:4000`.
